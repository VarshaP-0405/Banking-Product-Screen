# Morrow Banking Products Dashboard

A responsive, single-screen banking products dashboard built with plain HTML,
CSS, and JavaScript. No build step, external packages, or backend are required.

Open `index.html` in a browser to run it. The product records are defined in the
JavaScript `products` array, separate from the rendering and filtering logic.
Category filters, text search, product details, category exploration, sidebar
navigation, and payment-review links all work locally. Recent activity,
payments, and product balances are illustrative mock data; this demo does not
connect to a bank or submit applications.
